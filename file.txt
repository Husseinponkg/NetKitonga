NET KITONGA API ENDPOINTS
=========================

Base URL
--------
Production: https://netkitonga.onrender.com
Local:      http://localhost:8000

FastAPI documentation
---------------------
GET  /docs       Interactive Swagger API documentation
GET  /redoc      ReDoc API documentation
GET  /openapi.json  OpenAPI schema

Health
------
GET  /
Returns the API health status.

Authentication and tenant accounts
----------------------------------
POST /auth/register
Body: { business_name, system_name, email, password }
Creates a tenant account.

POST /auth/login
Body: { email, password }
Logs in a tenant and returns the tenant user information.

PUT  /auth/update
Body: tenant update payload
Updates tenant account details.

DELETE /auth/delete
Body: { id }
Deletes a tenant account.

Routers
-------
GET  /routers/?tenant_id={tenant_id}
Lists routers belonging to a tenant.

POST /routers/register
Body fields:
  tenant_id, branch_id, router_name, driver_type, mac_address, ip_address,
  is_licensed, status, last_heartbeat_at

  MikroTik fields:
    nas_identifier, radius_secret

  Ruijie/Wifidog fields:
    gw_id

The ip_address field is the physical router management IP address.
The response also returns a generated hardware_config_block provisioning script.

PUT  /routers/update
Body fields:
  router_id, router_name, driver_type, mac_address, ip_address,
  nas_identifier, radius_secret, gw_id, is_licensed, status
Updates a router configuration.

DELETE /routers/delete
Body: { router_id }
Deletes a router.

GET  /routers/status?router_id={router_id}
Returns the router status and last heartbeat time.

GET  /routers/mikrotik/ping?nas_id={nas_identifier}
Physical MikroTik RouterOS heartbeat endpoint.
The generated MikroTik script calls this endpoint every minute.
Render example:
  https://netkitonga.onrender.com/routers/mikrotik/ping?nas_id=YOUR_NAS_ID

GET  /routers/wifidog/ping?gw_id={gateway_id}
Physical Ruijie/OpenWrt Wifidog heartbeat endpoint.
Returns plain-text Pong when the gateway is recognized.

WiFiDog captive portal gateway
------------------------------
These endpoints are used by Ruijie/OpenWrt WiFiDog captive portal integrations.

GET  /wifidog/ping
Heartbeat endpoint. Returns plain text: Pong

GET  /wifidog/auth
Checks whether a client is authorized to access the internet.
Query params: gw_id, mac, ip, url
Returns plain text: Auth: 1 or Auth: 0
Logic:
  - Looks up router by gw_id
  - Looks up buyer by MAC
  - Looks up active, non-expired active_sessions by router + buyer (+ IP if provided)
  - If found -> Auth: 1, otherwise Auth: 0

GET  /wifidog/login
Redirects the client to the captive portal.
Query params: gw_id, mac, ip, url
Redirects to: https://net-kitonga.vercel.app/portal?...

GET  /wifidog/portal
Same as /wifidog/login; redirects the client to the captive portal.
Query params: gw_id, mac, ip, url
Redirects to: https://net-kitonga.vercel.app/portal?...

GET  /wifidog/msg   
WiFiDog message endpoint.
Query param: message
Returns plain text: Message: {message}

GET  /wifidog/register
WiFiDog register endpoint.
Returns plain text: OK

Active sessions
---------------
GET  /sessions/active?tenant_id={tenant_id}
Lists active internet sessions for a tenant.

POST /sessions/terminate
Body: { tenant_id, session_id }
Terminates an active session.

Note: active_sessions are automatically created when:
  - A payment webhook callback succeeds for completed payments
  - A voucher is redeemed via POST /vouchers/redeem

Important deployment notes
--------------------------
1. The frontend currently uses VITE_API_URL when configured; otherwise it uses:
   https://netkitonga.onrender.com
2. Physical MikroTik routers must be able to reach the deployed HTTPS API.
3. The MikroTik NAS identifier or Ruijie gateway ID must match the router record.
4. The routers table must contain the ip_address INET column.
5. Do not expose database passwords in source files or public documentation.
6. For Ruijie WiFiDog routers, configure:
   - Auth Server: https://netkitonga.onrender.com
   - Auth Server Port: 443
   - Auth Server Path: /wifidog/
    - Heartbeat: /wifidog/ping?gw_id={gateway_id}
